# UniTareas

## Descripción del proyecto

UniTareas es una aplicación web diseñada para ayudar a los estudiantes a organizar sus actividades académicas, registrar tareas, controlar fechas de entrega y administrar mejor su tiempo.

La aplicación también contará con una funcionalidad de inteligencia artificial que ofrecerá recomendaciones para mejorar la planificación y organización de las actividades académicas.

## Público objetivo

Está dirigida a estudiantes de educación secundaria, técnica y universitaria que necesitan una herramienta sencilla para organizar sus responsabilidades académicas.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- React
- Vite
- Firebase
- API REST Nager.Date
- API de inteligencia artificial Gemini
- Git y GitHub

## Funcionalidades principales

- Registro e inicio de sesión de usuarios.
- Creación, edición y eliminación de tareas.
- Organización de actividades por fechas de entrega y prioridades.
- Consulta de tareas pendientes y completadas.
- Almacenamiento de información en la nube.
- Recomendaciones inteligentes para organizar las actividades académicas.
